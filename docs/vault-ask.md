# Optional external Vault Q&A

本包只提供调用约定，不复制 RAG 程序、向量库、模型或授权。用户审查自己的入口后，在本机 registry 登记 vault-ask。普通问答只读；新近归档可用原文层；索引更新仅在明确授权后限定已保存文件。

切换 SQLite 日志策略前先一致性备份，在外部副本验证增量、并发读取、锁等待和保留新数据的回退；正式转换要单独批准。DELETE + EXTRA 可作为只读 WAL 伴随文件受限时的候选，但存在读写互等与写同步成本，不是通用权限修复。不要对实时库使用 immutable=1，不删除 WAL/SHM，不用旧库覆盖新增记录。本系统安装不触及用户现有数据库。
