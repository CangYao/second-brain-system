# Quick Start

1. 用 setup 初始化后，在 Obsidian 与 Codex 打开**生成的 Vault**。
2. 向 Codex 给出一段内容并说“把这个知识点整理进知识库”。Agent 读取 AGENTS → ROUTER → Inbox 概念分支；按需读模板、局部匹配，保留证据后创建或更新。
3. “把这本书加入书库”走 Book；“我突然想到……”走 Thought；“记录一下今天……”走 Daily；“整理 Inbox”只处理指定范围。
4. “根据这些长期信息更新对我的了解”才进入 Personal-Model；普通推荐不会自动反向学习。
5. “带我读”用 ai-reading；单材料深加工用 deep-reading；需要外部证据才 research，多源有实质比较才 synthesis。不是每次都跑全链。

所有普通内容任务仍需实际阅读材料、核对来源、正文与 YAML、检查重复对象。系统不会因为一份模板存在而保证 AI 理解正确。没有 Git 时报告 NOT_CONFIGURED，保留已验证内容；有已配置本地仓库时 scoped local commit，永不默认 push。

[示例目录](../examples/)均为 SAMPLE/FICTIONAL/DEMO，不代表用户背景或实际观看、研究。不要把演示观点当成自己的长期偏好。开用不需要填写巨型个人问卷，也不需要下载模型。
