# Learning platform and archived outcomes

PDF 导入、整书分析、课程/课时、教学、训练和错题复习由用户自己的学习平台负责；Codex 提供入口、接入与维护；Obsidian 存审核后的长期成果。这里不捆绑 DeepTutor、个人账号或完整课程。

选定真实材料 → 在平台按课时学习和答题 → 平台管理复习 → 用户选取并审核成果 → Codex 匹配原笔记、保留旧理解及真实来源 → Bases 汇总归档 → Canvas 关联教材/课程/知识 → 授权后限定更新问库。学习进度不搬到第二套表中。

可选复制 examples/Learning-SAMPLE 到自己的 08_Projects/Learning-SAMPLE；它没有真实归档成果。先核对自己安装的 Obsidian 是否支持 Bases/Canvas，再打开 .base/.canvas。示例不是课程导入器或自动同步插件。
