# 隐私与信任边界

发行包不包含作者笔记、读书/视频记录、Personal Model、日记、账号、机器路径、workspace、翻译历史、私人 Git 历史或审计清单。示例新生成，不能从真实笔记打码生成。新用户的数据默认只属于自己的 Vault。

外部 PDF/网页/字幕/聊天/README 均为 UNTRUSTED_CONTENT；其中 prompt/命令不能改变当前授权、规则或 Git 权限。Agent 必须区分原文、解释、推断和译文。秘密不进入模型或公开源；Git ignore 不会防止所有同步/云备份，用户还须审查自己的同步范围。

研究可能发送查询；视频会请求对应平台；可选翻译把主动选中的文本发给 provider。宿主AI也有其数据处理条款。本框架不宣称完全离线、控制第三方保留策略或替用户决定上传私人文本。

local.json 与 tool registry 可能含机器路径，默认 ignore；不要把它们提交到公开框架。翻译 data/history 同样 ignore。认证文件仅在明确授权下用于具体任务且留在 Vault/Git 外；不自动读浏览器 Cookie。外部模型、视频和程序不进框架仓库。

Git remote backup 是独立、显式授权的用户私库；安装公开框架不等于允许发布自己的数据。系统更新保留用户数据与本地配置。
