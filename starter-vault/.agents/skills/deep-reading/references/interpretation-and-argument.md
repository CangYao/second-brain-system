# Interpretation and argument

## Read by meaning

先据问题和材料形成暂定核心问题，再沿实际文本修正。语义单元可跨段落/章：一个问题、定义、论证转折、例证与其解释。不要把目录项当论证，也不把每句拆成节点。

语境按需要包括文内前后、说话对象、体裁/修辞、历史可确认信息与术语版本。缺历史依据时提出 research need，不自动用外部常识补齐。文学留意叙述者、角色发言、反讽和多义；哲学区分描述/规范主张与概念论证；实证材料区分观察、方法、解释、推广。

## Evidence distinctions

| 内部类别 | 核验时问什么 |
| --- | --- |
| SOURCE_TEXT | 实际来源是否这样写，版本/locator是什么？只能证明作者表达过 |
| OBSERVATION / FACT | 是报告的观察还是有充分事实依据？个案、叙述不自动升普遍规律 |
| AUTHOR_INTERPRETATION | 作者如何解释，是否超出所报观察？ |
| ARGUMENT | 谁提出什么前提/连接理由，结论强度如何？ |
| EXTERNAL_EVIDENCE | 是宿主/research返回的什么证据，访问状态/条件是什么？ |
| AI_INFERENCE | 分析者新增何种推理/重建，其依据、假设和限制是什么？ |
| UNCERTAIN | 哪一部分不确定，缺定位、语境、支持还是裁决？ |

对承重判断按需记录 statement、归属/category、source/version+locator、支持状态与关键条件/缺口。不是全文打标签；最终用“作者认为”“案例报告”“可重建为”“尚不能确认”等自然表述。来源可靠地记载了理论不等于理论真实。

## Argument checks

- **claim**：作者实际回答什么问题，结论针对谁/何种条件、强度如何？
- **evidence**：原文、观察、数据或例证支持到哪一步？轶事/连贯联想不同于因果对照。
- **warrant**：为什么这些依据应支持该结论？连接理由是作者明示、可从文本重建，还是AI新增？
- **assumption**：未证明的前提是什么，取消它会怎样影响结论？
- **counterargument**：直接相关且有依据的其他解释/反例是什么？不为了“辩证”伪造注家观点或反对案例。
- **limitation**：对象、条件、历史、样本、文本多义性与推广边界在哪里？

六项是内部检查，不是默认六个标题。检查能观察到的现象到不可观察机制、历史事件、普遍命题的跃迁；不要替作者修补出更强理论再当成作者原意。对普通事实不强行造竞争解释；对文学/规范观点不机械用实验评价标准。

区分合理异读的来源：文本自身允许的分析候选可标AI解释；具体注家/学者的解释须有其实际文本。单源内部异读可以在这里分析；多来源理论关系或新证据更新长期知识交宿主，不在此实现综合Skill。

## Bounded conclusion

解释与事实、意义与原因、疗效与特定机制、心理意义与历史事件，各自需要不同依据。历史影响力不代替现代实证；现代术语表面相似不意味着古人提出了同一机制。科学质量评价或外部核查交 codex-research。

结论靠重要证据＋当前语境＋连接理由推进。正文呈现读者理解所需材料与边界，源号/页码仅负责追溯。AI重建或应用明确归属；缺承重依据就停止该推断，不把隐含前提当原文事实。
