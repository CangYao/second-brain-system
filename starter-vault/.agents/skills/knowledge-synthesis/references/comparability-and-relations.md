# Comparability and relations

## Source qualification and two-stage gate

先确认共同问题是否真实存在，再细对齐承重概念后确认 gate；不能仅看到同一个词就预判可比。逐源只查影响比较的身份/版本、原始或二手性质、实际已读单元、定位、解释归属、关键缺口和谱系。没有理解一方就记录 SOURCE_UNDERSTANDING_INSUFFICIENT，经宿主补读。

| 对齐维度 | 要判断的差别 |
| --- | --- |
| Definition | 术语实际所指、外延/排除项、命题对象；译词相同是否掩盖异义 |
| Context | 文内问题、受众/体裁、历史/学科背景和版本 |
| Theoretical level / role | 规范建议、描述、解释机制、隐喻、测量构念是否同层 |
| Mechanism | 实際主张的过程/因果假设；只有结构类比还是机制证据 |
| Evidence type | 文本、逻辑、临床个案、观察、实验、二手解释分别支持什么 |
| Scope | 对象、条件、时间、尺度、量词及结论强度 |

伦理/文学材料没有经验机制时标不适用，不填造因果链。来源定义可以被准确比较，不表示主张真实或证据同权。gate 仅针对当前命题/维度：
- COMPARABLE：足以直接比较所指定命题及条件。
- PARTIALLY_COMPARABLE：有明确共同维度，也有不能互换/直接验证的部分；写出允许与禁止的比较。
- NOT_COMPARABLE：已确认拟比较对象/问题不同，不能直接融合；可另有受限类比，不强求。
- UNDETERMINED：定义、理解或证据缺口使 gate 未定；不以资料不足输出确定 UNRELATED。

不机械填写六维大表。最终解释为何能比、比到哪里、为何不能合并。相同主题可包含不同知识对象；同一对象也可容纳不同立场，文件匹配由 Workflow 处理。

## Agreement, difference and contradiction

先定位两方具体命题和支持内容。一致可发生在词义、价值取向、结构、机制或结果层，不可把两源一致称为领域科学共识。分歧可能来自对象、定义、时期、条件、理论角色或证据，而非逻辑相反。

冲突先核对共同问题、定义、时间背景、理论层级、证据类型、样本/对象/范围与是否仅加入限定：
- APPARENT_CONFLICT：差异来自条件/含义/层级，调整后不构成同命题互斥；说明原先怎样误读。
- GENUINE_CONTRADICTION：对齐之后关键命题仍不能同时成立；保留双方出处和证明力度。
- 裁决不足：保留 unresolved，不按最新、名气、多数或文风选边；转外部研究需求时只交具体问题。

统计未显著不自动证明没有效应；不同证据类型不自动互相反驳。发现历史主张与现代构念不同，不等于其历史主张已被证实或证伪。

## Relation candidates

只在有实质用途和证据时提出。每条给比较对象/具体命题、relation、方向（非对称时）、维度、双方 evidence+locator、rationale、关键差异/条件与未决；rationale 解释证据为何支持，不能只复述标签。

| Relation | 最小成立条件 | 拒绝条件 |
| --- | --- | --- |
| SAME | 当前范围内定义、对象、角色和条件足够等价，互换不改关键意义，双方可定位 | 同词/同标题/译词近似不够；不授权文件合并 |
| RELATED | 在明确问题/维度存在可说明的实质联系，各方有支持内容 | 仅同主题/共现/标签 |
| EXTENDS | B兼容A核心判断并增加有据的新维度、解释结构或范围，说明B→A增量 | 重述或多一个同条件例子不等于扩展 |
| CONSTRAINS | B有据地限制A某命题的条件/边界，说明B→A与被收窄处 | 不同话题或缺证据不能证明限制 |
| CONTRADICTS | 同对象/条件/范围下主张不能同时成立且冲突可定位 | 定义不同、零结果、不同时间不直接推出矛盾 |
| ANALOGOUS | 指明相似的结构/作用/机制维度及断裂点，有解释用途 | 类比不提供独立证明、同义或历史影响 |
| HISTORICALLY_RELATED | 有可追溯传承/引用/影响依据，限定对象和方向 | 先后出现、同属传统或词语相似不够 |
| UNRELATED | 当前问题/维度已确认拟议联系不成立，给理由 | 不代表永远无任何联系；资料不足保留未定 |

关系可按不同命题有不同判断，不堆标签；RELATED 不能作为跳过比较的模糊兜底。不可比可 NO_RELATION / KEEP_SEPARATE；有明确映射和用途才给受限 ANALOGOUS。局部相似不抹掉整体差别。
