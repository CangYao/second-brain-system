# 阅读书架

[[02_Topics/第二大脑首页|首页]] · [[08_Projects/项目总览|项目总览]] · [[03_Books/阅读书架.base|打开完整书架]] · [登记书籍](obsidian://quickadd?choice=%E6%96%B0%E5%A2%9E%E4%B9%A6%E7%B1%8D)

从书名回到阅读笔记，按阅读状态切换视图。**未登记**表示尚未明确记录阅读状态。

![[03_Books/阅读书架.base#全部书籍]]

> [!info]- 数据口径
> 书架读取 `03_Books/Fiction` 与 `03_Books/Nonfiction` 中 `type: book` 的真实笔记，排除模板和验收样例。作者、分类与日期来自原笔记属性；“笔记更新”是内容更新日期，不代表最近阅读日期。
>
> 阅读状态沿用原字段：`planned`、`reading`、`paused`、`completed`，中文名称只在视图中展示。缺失状态显示“未登记”，不会根据笔记内容或文件修改时间推定。书架不补写原书籍字段，未设置封面的书籍以文字卡片展示。
>
> “登记书籍”需先安装并导入现有 QuickAdd Starter 配置；也可以继续用原有书籍模板记录。
