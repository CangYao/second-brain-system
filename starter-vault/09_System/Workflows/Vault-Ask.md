# 可选问库

问既有知识走本入口；外部研究走 research。Canonical dependency 为本机 `09_System/Config/tool-registry.local.json` 的唯一 vault-ask 条目；公开包不捆绑 RAG 程序、索引数据库、模型或凭据。未配置时报告 NOT_CONFIGURED，不扩大搜索或自动安装。

支持本系统约定的外部入口时，调用 `kb.ps1 ask "问题"` 或 `kb.ps1 search "问题" --layer source -k 8`；实际参数以该工具说明为准。新近归档和精确事实优先原文层；召回缺失不等于笔记不存在。捕获退出码、来源编号和依据路径，网络/权限/模型失败如实说明，不编造答案。

普通问库保持只读。只有用户明确授权索引维护后，才对已保存核验的文件用 `index --file` 限定更新；不默认全库扫描，不生成概览或提交。备份、个人模型种子、验证夹具与隐藏运行数据应从该外部索引排除，并由部署者核验。

SQLite 的只读 WAL 可能受伴随文件访问条件影响；不得据此判定损坏、重建或加 immutable 绕过锁。若考虑 DELETE + EXTRA，应先一致性备份，在独立副本验证增量、并发、受限读取和恢复，再由用户批准正式转换；只改连接策略，原数据保留。公开安装不会修改用户已有数据库或权限。更多说明见项目包 docs/vault-ask.md。
