# 学习平台、Codex 与长期成果

采用 DeepTutor 等独立学习平台时，PDF 识别与解析、整书分析、课程拆解/分类、逐课引导、练习题库、错题复习和连续学习进度由平台承担。Codex 引导入口、协助接入、诊断与授权维护；Obsidian 接收用户选定并审核的长期成果。不因本约定认定某平台已安装或全部能力可用。

归档先匹配原笔记，保留旧理解和来源。整篇审核的成果用 archive_reviewed 布尔值与 archived_on 日期；混合笔记只在 archived_sections 字符串列表登记真实已审章节/块 Wikilink，不能把整个计划标成完成。sources/relations 沿用既有列表字段，课程链接使用真实完整 URL，不虚构平台 ID。

Bases 从原笔记属性汇总归档成果；Canvas 展示教材、课程与知识关系，后续按实际来源增量维护，不复制实时进度。未确认归档成果时表格应为空。包内 examples/Learning-SAMPLE 是新生成的空成果示例，只有明确选择才复制，不是原作者学习记录。

保存验证通过且索引维护已授权时，使用已配置外部问库入口作限定文件索引；成功才报告已同步，失败保留笔记并报告待更新。学习平台未接入问库时，问课时/错题/复习进度应回到平台核对。
